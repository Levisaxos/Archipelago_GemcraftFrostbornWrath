# GemCraft: Frostborn Wrath — Archipelago

A randomizer mod for **GemCraft: Frostborn Wrath** built on the [Archipelago](https://archipelago.gg) multiworld framework.

## For players

- **Install & setup, options, and troubleshooting:** see the main [README](../README.md).
- **Disclaimer & credits:** [disclaimer.md](disclaimer.md).

That's everything you need to play. Download `ArchipelagoMod.swf` and `gcfw.apworld` from the [Releases](../../releases) page and follow the main README.

## For developers

Building from source is covered in [Developer_Setup.md](../Developer_Setup.md). The in-depth technical documentation (how the mod and apworld actually work) is maintained privately by the author and is not part of this repository.
